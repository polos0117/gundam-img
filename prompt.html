v9.4 변경 내역 패치 노트
v9.4 · 단일 컷 패널 재배치
  • 쓰는 빈도대로 다시 쌓았다. 랜덤 성격 셀렉트와 버튼 세 개가 맨 위로 올라오고, 카테고리 · 예시가 바로 따라온다
  • "랜덤으로 정할 것" 체크박스 8개를 접었다. 한 번 정하면 거의 안 건드리는데 화면 위쪽을 크게 차지하고 있었다. 접힌 채로도 몇 개를 켜뒀는지 요약 줄에 보인다
  • 직접 입력 4개(장면 · 의상 · 카메라 · 추가 지시)를 한 블록으로 묶어 접었다. 값이 들어 있으면 몇 개 입력됐는지 요약 줄에 뜬다 — 접어둔 채로 잊고 왜 이렇게 나오는지 헤매는 일을 막는다
  • 접힘 상태와 랜덤 대상 체크가 저장된다. 새로고침해도 펴둔 건 펴진 채로 돌아온다
v9.3 · 랜덤 · 화풍 라벨 정리
  • 화풍 이름을 갈랐다 — 세미리얼 시네마틱(cinematic_semi_real) / 세미리얼 유화(semi_real_paint). 기존 "세미리얼 페인팅 / 반실사 회화"는 서로 같은 말처럼 읽혀 구분이 안 됐다. 내부 키와 저장된 기록은 무변화
  • 단일 컷에 자체 랜덤 성격 셀렉트를 붙였다. 예전에는 단일 컷 랜덤이 콜라주 패널의 셀렉트를 몰래 따라가서, 단일 패널만 보고 있으면 왜 같은 카테고리가 반복되는지 알 방법이 없었다. 기체친화형은 세 Pair 에 추천을 꽂는 모드라 단일 목록에서 뺐다
  • "이미 쓴 조합 피하기"도 패널별로 분리했다. 단일은 sgAvoid, 콜라주는 기존 체크박스를 각자 본다
  • 랜덤을 굴리면 카테고리 후보가 몇 종 남았는지 상태줄에 찍는다. 회피를 켜두면 이미 쓴 카테고리가 빠지면서 후보가 한두 종까지 줄어드는데, 지금까지는 아무 표시가 없어 랜덤이 고장난 것처럼 보였다. 2종 이하로 줄면 경고색으로 뜬다
  • 다양성형 설명에서 "여섯 컷" 표현을 단일 컷 목록에서만 "카테고리 전체에서 고르게"로 바꿨다. 콜라주 쪽 문구는 그대로
  • 설정 예시 갤러리 엑박 수정 — 파일명을 카드 이름으로 조립하던 것을 실제 파일명을 쓰도록 고쳤다. 이름에 띄어쓰기가 있는 카드 76기가 전부 안 뜨던 문제
v9.2 · Morphology Mode 추가
  • 의인화 탭에 Morphology Mode 셀렉트 신설 — 표준형 / 실루엣·장비 강조형 / 강변형형 3종
  • 바이아란처럼 인간형과 거리가 있는 기체를 위한 것. 기체별 자동 분류는 하지 않고 사용자가 직접 고른다 — 정답 하나를 강제하지 않는다
  • 일상컷(콜라주·단일컷)에는 이 블록이 구조적으로 아예 조립되지 않는다 — 넣고 무시하는 게 아니라 애초에 그 함수가 이 블록을 모른다
  • 세미리얼·게임 키아트 골든 페어와 나머지 9개 화풍 전부 무변화
v9.1 · 구조 완성 — 11개 화풍 전체 이관
  • 세미리얼·게임 키아트 2개만 쓰던 새 구조를 11개 화풍 전체로 확장했다. 모든 화풍이 STYLE_PROFILES 한 경로로 통일됐다
  • 나머지 9개 화풍에서도 갑옷·무기 관련 문장을 의인화 전용으로 분리했다 — 일상컷에서 문구가 안 보여도 실제로는 이번에 처음 빠진 화풍이 많다
  • TRANSLATION PROFILE(Human ↔ Mechanical Balance 문단화)이 이제 11개 화풍 전체 의인화에 적용된다
  • 모드 누수 자동 점검을 넣었다. 일상컷 프롬프트에 의인화 문구가 섞이거나 그 반대인 경우 콘솔에 경고가 뜬다
  • 세미리얼·게임 키아트의 실제 문구는 이번 패치에서 한 글자도 바뀌지 않았다 — 구조만 옮겼다
v9.0 · 화풍 아키텍처 파일럿
  • 세미리얼·게임 키아트 2.5D 두 화풍만 STYLE CORE(공통) · ANTHRO EXTENSION(의인화 전용 갑옷 규정) · LIFESTYLE EXTENSION(일상컷 전용 소재 규정)으로 분리했다
  • 같은 화풍이라도 일상컷 프롬프트에는 이제 갑옷 · 무기 · 백팩 언급이 아예 안 들어간다. 다른 9개 화풍은 기존 방식 그대로, 회귀 없음을 함수 단위 테스트로 확인했다
  • TRANSLATION PROFILE 신설. Human ↔ Mechanical Balance 값(More Human / Balanced / More Mechanical)에 맞춰 인간화 정도를 문단 단위로 지시한다 — 두 파일럿 화풍의 의인화에서만 적용
v8.4 · 일상컷 메카 재생성 방지 + 화풍 레퍼런스 강화
  • 의인화용 STYLE LOCK과 일상컷(콜라주·단일컷)용 STYLE LOCK을 분리했다. 일상컷 화풍 지시에서 armor · weapon 언급을 빼서 화풍이 메카 의미론을 다시 불러오지 않는다
  • LIFESTYLE REFERENCE LOCK 신설. 수영장 · 홈웨어 같은 일상컷에서 기준 이미지에 없던 갑옷 · 방패 · 메카 파츠가 새로 생기던 문제를 막는다
  • 기체명(SOURCE MOBILE SUIT)은 이제 직업 · 로어 맥락용 메타데이터로만 쓰이고, 장비 복원 근거로 쓰지 말라고 못 박았다
  • 세미리얼 페인팅에 MECHANICAL PAINTERLY LOCK 추가. 장갑이 정교해도 CGI/PBR 렌더로 안 튀게 잠근다
  • 게임 키아트 2.5D를 다시 정의했다. 평면 애니로 처지던 문제를 고쳐 "평면 애니와 풀 3D CGI 사이" 볼륨감 있는 키아트로 좁혔다
  • REFERENCE IMAGE AUTHORITY 추가. 업로드 레퍼런스가 실루엣 · 비율 · 장비 배치의 1차 권위를 갖고, 화풍은 렌더링 언어만 정하며 캐논 기억은 레퍼런스에 안 보일 때만 보조로 쓰인다
  • 로브형 · 망토형 · 드레스형 하체 장갑을 원기체 레퍼런스나 PARAMETERS가 뒷받침할 때만 허용하도록 제한했다
v8.3 · 화풍 프리셋 재정비
  • 11개 화풍을 전면 재작성. 화풍마다 얼굴 · 피부 · 머리 · 장갑 · 조명 · 배경 · 금지사항을 따로 정의한다
  • STYLE LOCK 추가. 선택한 화풍이 이미지 전체의 렌더링 언어를 지배하고, 다른 지시와 충돌하면 화풍이 이긴다
  • 의인화 공통 조명을 화풍 중립으로 교체. 어두운 스튜디오 배경 · 림라이트 · PBR 재질 강제가 사라져 셀화 · 레트로 · 수묵이 제 결로 나온다
  • 얼굴은 회화적인데 메카만 CG로 튀던 문제 수정. PBR은 게임 시네마틱 CGI 화풍에서만 허용한다
  • 한국형 글로시에서 마른 체형 · 바로크 장식 강제를 제거. 캐릭터 디자인은 PARAMETERS와 원기체를 따른다
  • 게임 키아트에서 single-character 문구 제거. 콜라주 6패널 구조와 충돌하던 표현이다
  • 양쪽 눈 색이 같으면 오드아이로 처리하지 않는다. 프롬프트와 미리보기를 모두 고쳤다
